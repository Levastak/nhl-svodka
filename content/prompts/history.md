Составь файл trigger/hist: по строке на запрос — «player <id>» для каждого главного игрока (id — последний сегмент адреса в site/data.json → heads["Latin Name"]; для ушедших из лиги игроков id найди поиском, например «<имя> NHL player id» на nhl.com/player/…), «photos <запрос по-английски>» — 2–4 запроса на свободные фото (например «Patrick Kane Blackhawks», «Detroit Red Wings 1997 Stanley Cup»). Закоммить ТОЛЬКО этот файл отдельным коммитом: git add trigger/hist; git commit -m "История: запрос данных"; git pull --rebase origin main; git push origin HEAD:main. Важно, чтобы этот коммит был последним в push — по нему GitHub запускает режим hist. Затем каждые 2 минуты git pull и проверяй появление site/hist/player-<id>.json и site/hist/photos-<slug>.json (до 8 раз). ШАГ 5. Статья. Новый объект в НАЧАЛО списка site/stories.json (остальные статьи не трогай). Формат как у вышедших статей:
{"id":"<латиницей-через-дефис>","kind":"story","kicker":"История","title":"<до ~90 знаков, с интригой>","dek":"<2 предложения: о чём и почему интересно>","time":"<сейчас ISO UTC>","teams":[аббревиатуры НХЛ 1–3],"players":[до 8 полных имён латиницей точно как в site/data.json (skaters/goalies/heads) — по ним сайт показывает фото и карточки; ушедших из лиги игроков пиши как на NHL.com],
"cover":{"url","credit":"<автор> / Wikimedia Commons, <лицензия>","link":"<страница файла>"},
"facts":[4–6 карточек {"v":"<число или короткое слово>","l":"<подпись>"}],
"chart":{"title","items":[{"label":"21/22","value":108,"hl":true|false}],"after":<номер блока body, после которого стоит график>,"note":"<что выделено и вывод>"},
"charts":[ещё 0–2 графика того же формата — по желанию],
"body":[блоки по порядку: абзац — строка; подзаголовок — строка «## Заголовок»; выноска — строка «> короткая цифра или мысль»; фото — {"img","cap":"<подпись по-русски: кто, где, когда>","credit":"<автор> / Wikimedia Commons, <лицензия>","link"}],
"sources":[список источников строками: «NHL.com (api-web.nhle.com)», «Wikimedia Commons», «ESPN: <о чём>»…]}
Структура: зацепка из сегодняшнего дня (матч, рекорд, повод) → 5–7 разделов с подзаголовками по хронологии или по смыслу → «Что дальше» или «Что осталось» — связь с нынешним сезоном по нашим данным (site/data.json, archive.json). 2–4 выноски, 2–4 фото внутри текста. Обложка и фото — ТОЛЬКО из site/hist/photos-*.json с ok = true (url, author, license, page); подпись к фото — по его описанию (desc, date), не придумывай, кто на снимке. Нет подходящих фото — обложку не ставь (сайт нарисует обложку из логотипов клубов), фото в тексте не вставляй. Графики — по реальным данным (карьера игрока по сезонам, процент очков клуба и т.п.).

ЯЗЫК И ИМЕНА. Только по-русски, без латиницы в title, dek, body, facts, chart. Клубы — русскими названиями в кавычках («Чикаго», «Детройт»); исторические клубы и сборные — как в российской прессе. Фамилии игроков — СТРОГО по словарю site/names_ru.json ({"Latin Name":"Русское Имя"}), со склонением, основу не меняй: этот словарь показывает имена в карточках игроков. Игроков, которых нет в словаре (ветераны), добавь в словарь в написании российской спортивной прессы (sports.ru, «Чемпионат»; россиянам — родное), существующие записи не меняй; сохрани json.dump(..., ensure_ascii=False, indent=0, sort_keys=True). Десятичные дроби — через запятую. Мнение помечай как мнение. Это хоккейная история, а не ставки — о ставках и коэффициентах не пиши.
