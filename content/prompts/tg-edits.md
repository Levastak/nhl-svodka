# Задача «Сводка НХЛ: правки канала» (раз в час с 9:35 до 23:35 по Кирову, Sonnet)

Полный промпт задачи. Сама задача только обновляет репозиторий и выполняет этот файл. Правки — коммитом сюда.

Лев пересылает кривой пост из канала @nhlstatsru в личку бота @nhlstatsru_bot и пишет, что не так. GitHub (scripts/tg.py, режим auto, раз в 15 минут) складывает такие заявки в tg/edit_requests.json: {message_id, key (ключ поста, если он из сегодняшнего плана), note (что не так — словами Льва), text (текст пересланного поста без разметки), time, status: "new"}. Твоя работа — поправить текст поста. Сам пост на месте редактирует GitHub по твоему файлу tg/edits.json и пишет Льву «Поправил».

ШАГ 1. Прочитай tg/edit_requests.json. Если заявок со status = "new" нет — итог одной строкой «заявок нет» и заверши работу, ничего не коммить.

ШАГ 2. Запусти python3 scripts/tg.py texts — он запишет tg/post_texts.json: HTML всех постов текущего плана (key, message_id, text). Для каждой новой заявки найди исходный HTML по message_id или key. Если поста там нет (старый день) — собери HTML сам из text заявки: первая строка жирным (<b>…</b>), абзацы через пустую строку, в конце ровно такая подпись: \n\n🏒 <a href="https://levastak.github.io/nhl-svodka/">NHL-STATS.RU</a> — статистика, прогнозы и аналитика НХЛ по-русски (адрес сайта возьми из константы URL в scripts/tg.py — он мог смениться).

ШАГ 3. Поправь текст: ровно то, о чём просит Лев, плюс очевидные ошибки рядом (опечатки, кальки, не то склонение). Структуру, ссылки, жирные заголовки и подпись сохрани. Факты, если Лев их оспаривает, проверь по нашим данным (site/data.json, site/archive.json, site/box.json) и при необходимости поиском (WebSearch, затем WebFetch). Фамилии — по site/names_ru.json. Правила языка — как в content/prompts/telegram.md (раздел «ЯЗЫК»). Длина: у поста с картинкой видимый текст до 1024 знаков (если исходный был длиннее — значит это сообщение с превью, лимит 4096). Без эмодзи, кроме тех, что уже есть в ссылках поста (👉, 📖, 🏒).

ШАГ 4. Поправь и источник, чтобы сайт и будущие перерисовки совпадали с исправленным постом:
— key начинается с feed: → элемент с тем же id в tg/news_queue.json (title, text), затем python3 scripts/news_live.py;
— am:, stars:, rus:, number:, news:, game:, games:, col:, vsm:, modelweek: → соответствующее поле site/data.json → tg (night, morning, stars, russians, number, news, games[id], games_lead, column, vs_market, model_week); data.json сохраняй компактно: json.dump(..., ensure_ascii=False, separators=(",", ":"));
— если Лев пишет про картинку (не те цифры, не тот игрок) — исправь данные, из которых она рисуется, и в конце запусти перерисовку: в trigger/tg запиши три строки «recard», текущее время, key поста — и закоммить этот файл ПОСЛЕДНИМ отдельным коммитом. Если картинку так не исправить — status заявки "need_human" и объясни в summary.

ШАГ 5. В tg/edits.json (создай, если нет: {"items": []}) добавь {"message_id", "text": <исправленный HTML целиком>, "status": "ready", "summary": "<что поправил, одной фразой для Льва>", "request_time"}. В tg/edit_requests.json у заявки поставь status "done" (или "need_human") и summary. Проверь скриптом: JSON валиден, HTML-теги закрыты (<b>, <i>, <a>), видимая длина в лимите. Затем: git add tg/edits.json tg/edit_requests.json (и изменённые файлы источника); git commit -m "Telegram: правка поста <message_id>"; git pull --rebase origin main; git push origin HEAD:main (до 3 попыток; при конфликте — git rebase --abort, git reset --hard origin/main и повтори правку тем же скриптом). GitHub применит правку при ближайшем запуске канала (до 15 минут) и сообщит Льву.

ШАГ 6. Итог одной-двумя строками: какие посты поправил и что именно, сбои.
