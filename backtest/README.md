# Бэктест модели

Воспроизводимая проверка модели на 5 сезонах 2021–2026 (регулярка), день за днём: на каждый игровой день
заново собираются archive.json, data.json и prior.json только из того, что было известно до матчей,
и модель запускается как есть.

- `scripts/backtest_data.py` — данные: результаты API НХЛ, поматчевые данные MoneyPuck (команды, вратари, полевые).
  Источник xG — [MoneyPuck.com](https://moneypuck.com/data.htm), некоммерческое использование.
- `scripts/backtest.py` — прогон и метрики; несколько версий модели на одних и тех же входах.
- `candidates/` — версии модели на проверке (рабочая — `scripts/model.py`, её здесь не меняем).
- `run.txt` — параметры запуска; правка и пуш в main запускают workflow «Бэктест модели» в GitHub Actions.
- `results/<метка>/` — `report.md` (сводка), `summary.json`, `preds_<версия>.csv.gz` (прогноз по каждому матчу),
  `_prior/` (восстановленные prior.json), логи. Данные целиком — архив `backtest-data` у запуска в Actions (30 дней).

Приближения (одинаковы для всех версий): кэфов нет; вратарь — фактический стартовый; травмы — по пропущенным
матчам за последние 15 игр команды; смен тренеров нет.

Локально: `python3 scripts/backtest_data.py --out bt-data && python3 scripts/backtest.py --data bt-data --model v4.2=scripts/model.py`
