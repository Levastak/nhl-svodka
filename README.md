# Сводка НХЛ

Итоги ночи, таблица, лидеры и прогнозы модели на каждый матч НХЛ — по-русски.

- `site/` — сама страница и данные (публикуется на GitHub Pages).
- `scripts/fetch.py` — сбор данных (результаты, статистика, составы, xG, коэффициенты), запускается в GitHub Actions дважды в день.
- `scripts/model.py` — модель прогнозов (v4.1).
- Тексты (превью, разборы, колонка, новости) пишет Claude поверх собранных данных.

Прогнозы — мнение модели, а не рекомендация делать ставки.
